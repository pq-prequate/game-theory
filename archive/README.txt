Prequate — 24-Month Engagement Story (static export)

Open index.html in any browser. No build step, no server required.

Files
  index.html   full page markup
  styles.css   compiled stylesheet (Tailwind output + export overrides)
  app.js       vanilla JS: filters, expandable callouts, scroll reveals,
               month rail, contact modal, presentation deck
  fonts/       Awesome Serif VAR (roman + italic) brand fonts
  favicon.svg  Prequate mark

Interactions
  - Office filter chips collapse the timeline to one office
  - Emphasis callouts expand into the animated step sequence
  - PRESENT opens the 9-slide deck (arrow keys / space, swipe, Esc to exit)
  - "Talk to a partner" opens the enquiry form (submits via mailto)
